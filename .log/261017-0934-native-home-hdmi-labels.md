# 261017-0934 - Show HDMI CEC names on native Home tiles

Glasshouse-created HDMI bookmarks on an OLED55G36LA running webOS 9.2.2 had titles but no visible text when focused. The installed Home AppTile QML defaults title visibility to systemApp, which is false for these bookmarks. A live applicationManager update with titleVisible enabled was retained by listLaunchPoints and displayed immediately on the physical Home screen. EIM getAllInputStatus exposed the receiver and downstream console as SIMPLINK entries. These observations support native launch-point metadata updates rather than changing Home QML. The findings are recorded in docs/development/TV-RESEARCH.md.

The change makes titles visible and refreshes CEC names at startup, once a minute and when an input tile is added. Only exact launch-point IDs recorded by Glasshouse are updated. Duplicate names and IR profiles are excluded; failed discovery keeps the last title and unchanged titles cause no writes. Existing TV labels remain a fallback. The behaviour is gated to the verified webOS 9 Home implementation. The regression extends the existing module/Luna boundary test without a production seam used only by tests.

Hardware verification preceded automated checks: the Home module was deployed with v0.102.2, the server restarted, and the native HDMI 2 title displayed and scrolled through STEREO 70s / PlayStation 5 and the port. All four owned titles were read back as visible, including empty ports; configuration and tile order were preserved. The module in this branch is byte-identical to that deployment. The PR branch starts at upstream main e033be2; that complete newer base has not been deployed. A full TV reboot and other webOS generations were not tested.

On the final PR base, node test/run-all.js passed all 79 suites under Node 16.20.2 using the unchanged official runner. TypeScript, ES5, module-call, UI-ID, string, screensaver, deployment-drift, entity-stability and entity-fixture checks passed, as did shellcheck, server syntax checks, git diff --check and the IPK build. The official upgrade check passed from v0.80.8 and the nearest tag v0.101.1. A supplementary in-memory invocation selected the latest release v0.102.2 explicitly and also passed; no checker source was changed. Code review found no high-confidence defect.

Only the native Home label fix and its documentation are included. Earlier dashboard CEC experiments and local TV credentials, captures and backups remain outside this branch. The requested publication is a draft PR; merging remains the upstream maintainer's decision.
